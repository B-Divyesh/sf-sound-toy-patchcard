# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/), and
this project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-27

### Added

- Patchcard v1 TypeScript format, validator, URL-safe encoder, and JSON Schema.
- Accessible embeddable widget with parameter controls, waveform, JSON export,
  private-by-default link and QR sharing, printing, and local WAV adapter.
- Local-first demonstration site with saved cards, import, offline shell,
  privacy and terms pages, and a locally generated reference sound.
